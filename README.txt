SWEET 16 MOBILE SURPRISE

Mulai dari index.html dengan Live Server di VS Code.

Alur:
Loading -> PIN 6 digit -> popup jika salah / kado melayang jika benar -> klik kado -> bunga memenuhi layar -> tombol lanjut ke celebration.html.

Edit PIN di bagian atas welcome.js:
pin: "270927"
Ganti dengan PIN 6 digit pilihanmu.

Musik:
Taruh file MP3 di folder Lagu dengan nama lagu.mp3. Jika berbeda, edit musicPath di welcome.js. Browser mungkin memblokir autoplay; musik dicoba diputar saat kado dibuka.

Catatan: PIN ini hanya pengunci kejutan sederhana. Karena disimpan di JavaScript browser, bukan sistem keamanan sungguhan.
